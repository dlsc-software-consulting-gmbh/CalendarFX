# Security Policy

## Supported Versions

Security fixes are applied to the latest released version of CalendarFX only. Please make sure
you are using the most recent release available on
[Maven Central](https://central.sonatype.com/artifact/com.calendarfx/view) before reporting an
issue.

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions or
pull requests.**

Instead, report them through one of the following channels:

1. [GitHub's private vulnerability reporting](https://github.com/dlsc-software-consulting-gmbh/CalendarFX/security/advisories/new)
   (preferred), or
2. by email to **info@dlsc.com** with `CalendarFX security` in the subject line.

Please include as much of the following as you can, so that we can reproduce and assess the
issue quickly:

* the type of issue and the affected component or class,
* the CalendarFX, Java and JavaFX versions affected,
* step-by-step instructions to reproduce the problem,
* proof-of-concept code, if available,
* the impact you believe the issue has.

## What to Expect

* We aim to acknowledge your report within **five business days**.
* We will let you know whether the report is accepted, and keep you informed about the
  progress towards a fix.
* Once a fix is released, we will publish a security advisory and — unless you prefer to stay
  anonymous — credit you for the discovery.

Please give us a reasonable amount of time to release a fix before disclosing the issue
publicly.
